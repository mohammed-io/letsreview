# Move main package from cmd/letsreview/ to root

## Context

`go install github.com/mohammed-io/letsreview/cmd/letsreview@v0.0.3` fails because the Go module proxy takes longer to index subpackage paths. Moving `main` to the repo root allows `go install github.com/mohammed-io/letsreview@v0.0.3`.

## Value

Shorter install command, faster proxy propagation, matches popular Go CLI conventions.
